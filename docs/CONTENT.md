# 5. Primary Website Goals

The website should make it easy for a visitor to:

1. Understand what Body Planet offers.
2. Discover available courses.
3. Understand that Body Planet also has a traditional equipped gym area.
4. Find current opening hours.
5. Find the gym.
6. Contact Body Planet.
7. Understand how course reservations are currently handled.
8. Reach Body Planet's external platforms where appropriate.

The static website itself does not currently need to:

- create user accounts;
- manage subscriptions;
- process membership payments;
- implement course booking;
- implement authentication;
- manage member data.

Those functions are currently associated with the existing Body Planet mobile application.
